# Project instructions

Read CONTEXT.md and the relevant technical evidence before making consequential changes. Inspect actual source and patches when they resolve a discrepancy. Keep the current technical state synchronized with source and executed validation.

Comment code clearly and concisely. Prefer one maintained implementation with configuration for experiment differences. Do not create successive standalone applications or copy the project for each experiment. Remove obsolete temporary source after preserving important findings and durable regression coverage.

Distinguish hardware measurements, desktop measurements, simulations, derived estimates and plans. Never treat changed pixels as a quality result or desktop timing as device timing. Preserve model identities, normalization, quantization, split isolation and camera-owned final output.

Public files and distributable artifacts must exclude personal information, calendar chronology, machine inventories, local paths and private camera content. Do not import private context or transcripts into Git history. Use versions and anonymous experiment identifiers. Keep runtime diagnostics local and public exports allowlisted.
